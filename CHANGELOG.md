# Changelog

## 0.1.1

- The plugin is in the Hermes plugin catalog: install it with `hermes plugins install oxylabs-web-api`. No code changes.

## 0.1.0

- First release: `oxylabs` web provider for Hermes's `web_search` (`POST /v1/search`, optional country targeting) and `web_extract` (`POST /v1/scrape` as Markdown, optional JavaScript rendering, parallel pages, falls back to the asynchronous endpoint when a page is slow).
